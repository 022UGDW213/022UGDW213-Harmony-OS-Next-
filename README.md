# Harmony OS Next

> HarmonyOS NEXT development resources and examples by [022UGDW213 (Time Loops)](https://github.com/022UGDW213)

## About

This repository contains development resources, code samples, and documentation for **HarmonyOS NEXT** — Huawei's next-generation distributed operating system.

## Features

- ArkTS/ArkUI component examples
- Distributed capabilities demos
- Device connectivity patterns
- System service integration
- Security policy and architecture
