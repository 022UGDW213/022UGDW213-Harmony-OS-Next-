## 🐛 Reporting a Vulnerability

As a research project focused on **Cyber Security** and **Kernel Exploitation prevention**, we take security seriously.

### Disclosure Process
1.  **Do NOT** file a public GitHub issue for sensitive security vulnerabilities.
2.  Email details to: **security@cyberlab.research** (or `jjsp` directly).
3.  Include a Proof of Concept (PoC) if possible.

### Safe Harbor
We guarantee legal safe harbor for researchers who:
*   Act in good faith.
*   Do not access user data.
*   Allow us 90 days to patch before public disclosure.

## 🧠 AI-Powered Threat Detection
This repository uses an **AI Reasoning Core** (DeepSeek/Nova) to detect anomalies in real-time.
*   **Kernel Integrity**: `scan.sh` runs regularly to prevent unauthorized code patterns.
*   **Memory Safety**: The `memory.c` HAL uses strict boundary checks.
*   **System Reflection**: `brain.cpp` monitors system vitals for signs of intrusion.
